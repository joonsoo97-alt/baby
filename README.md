# 태명의 임신일기

식단 기록, 산모/아기 주간 일기, 주차별 체크리스트, 건강기록(몸무게·검진·음성녹음),
사진·동영상·음성 미디어를 한곳에 담는 개인용 임신 기록 PWA입니다.
빌드 도구 없이 순수 HTML/CSS/JS로 만들어졌고, 모든 데이터는 기기(브라우저)의
IndexedDB에만 저장됩니다 — 서버로 전송되지 않습니다.

## GitHub Pages로 배포하기

1. GitHub에 새 저장소를 만듭니다. (Private/Public 무관)
2. 이 폴더 안의 파일 전체(index.html, style.css, app.js, manifest.json, sw.js, icons/)를
   저장소 루트에 그대로 업로드합니다.
3. 저장소 **Settings → Pages** 로 이동합니다.
4. **Source**를 `Deploy from a branch`로, 브랜치는 `main`, 폴더는 `/ (root)`로 설정하고 저장합니다.
5. 1~2분 후 `https://[내아이디].github.io/[저장소이름]/` 주소가 생성됩니다.

## 휴대폰에 설치하기

- **iPhone(Safari)**: 위 주소로 접속 → 공유 버튼 → **홈 화면에 추가**
- **Android(Chrome)**: 위 주소로 접속 → 메뉴(⋮) → **홈 화면에 추가** / 또는 자동으로 뜨는 설치 배너 사용

설치하면 홈 화면 아이콘으로 일반 앱처럼 실행돼요. HTTPS로 서비스되는 GitHub Pages이므로
카메라·마이크(음성 녹음) 권한도 정상적으로 동작합니다.

## 데이터 백업

**설정** 탭에서:
- **내보내기**: 모든 기록을 JSON 파일 하나로 다운로드
- **가져오기**: 내보낸 JSON 파일을 선택하면 그대로 복원

기기를 바꾸거나 브라우저 데이터를 지우기 전에는 꼭 내보내기로 백업해두세요.

## 로컬에서 미리 확인하기

브라우저는 보안상 `file://`로 열면 일부 기능(서비스워커 등)이 제한될 수 있어요.
간단한 로컬 서버로 확인하려면 이 폴더에서:

```
python3 -m http.server 8080
```

이후 `http://localhost:8080` 으로 접속하세요.
